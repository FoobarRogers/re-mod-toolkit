## 判据备忘

- 首帧能否无缝接上前一循环（≤ ~5° = 无缝；≥ 25° = 接不上任何循环）
- 髋高（骨盆竖直分量）：站姿 / 跑 / 低姿态的量级因骨架而异，先在本项目里标定基准
- 身体转角量级：用于把"翻滚类"和"过渡类"分开
- 循环闭合性：首末帧 RMS ≈ 0 = 闭合循环；过渡动画不可能闭合
