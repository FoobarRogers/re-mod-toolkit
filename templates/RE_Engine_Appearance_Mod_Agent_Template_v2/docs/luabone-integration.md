# LuaBone 适配规范

## 目的

LuaBone 用于运行时调整骨骼/Transform，使非原生角色模型在玩家骨架、动画或特定场景中正确表现。

它不应被用来掩盖：
- 错误权重
- 错误 mesh bind pose
- 材质问题
- 贴图问题
- PFB 引用问题

## 开始前要确认

1. 目标模型对应的 `plxxx` / 部位。
2. 使用的骨骼名称是否真实存在。
3. 父子骨骼关系。
4. 需要改的是：
   - local position
   - local rotation
   - local scale
   - 或多个组合
5. 修改是：
   - 永久适配
   - 某部件适配
   - 某状态/形态适配
   - 剧情/任务特殊适配

## 骨骼规则

- 不凭截图猜骨名。
- 不因视觉上“整体歪”就直接逐骨修；先找共同父骨。
- 如果左右两个子骨同时以相同方向偏转，优先检查共同父骨或根级 Transform。
- 修改前记录原始值，便于回退。
- 不在每帧无条件重复写相同 Transform；使用状态变化/对象重建触发。

## 生命周期

LuaBone 适配必须考虑：

- 标题界面尚无 Player
- 读档
- 切图
- MasterPlayer 销毁 / 重建
- CG / 剧情
- 任务开始 / 结束
- 暂停/解除暂停（若项目涉及）

如果对象会重建，不要长期缓存旧 Transform。

## 与外观切换联动

若项目存在红书/蓝书/技能状态等多形态：

```text
状态变化
→ 确认当前模型/部位
→ 获取当前有效骨架
→ 应用该形态对应 LuaBone 配置
```

不要假设“同一路径换内容”后旧骨架对象仍有效。

## JSON 配置

如 LuaBone 使用 JSON：

- 文件名与目标角色/装备 ID 的关系写入 handoff。
- 只修改目标骨骼项。
- 保留未知字段。
- JSON 改动后先做语法校验，再进游戏。
- 大配置不要全文打印；只 diff 目标骨骼。

## 验证矩阵

至少按项目需要测试：

| 场景 | 必测 |
|---|---|
| 据点静止 | 是 |
| 任务动作 | 是 |
| 切图后 | 是 |
| Reset Script 后 | 是 |
| 外观/状态切换后 | 若支持切换 |
| 剧情/CG | 若项目要求 |
| 暂停/解除 | 若历史上有相关问题 |
